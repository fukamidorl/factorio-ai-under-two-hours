# 開発の時系列

[人間向けREADME](../../README.ja.md) · [AI操作手順](AI_OPERATIONS.md) · [English](../en/DEVELOPMENT_HISTORY.md) · [简体中文](../zh-Hans/DEVELOPMENT_HISTORY.md)

2026年11月の検証記録。初期の試走は Factorio 2.1.24、量産の通し試走と配布版は基本ゲーム 2.1.25。以下の自動化タイムは、特記したものを除いて自動操作を始めてからのゲーム内時間。

## 11月22日まで · 鉄板1枚から初号機へ

利用者は、インストール済みのゲームで AI かプログラムが新規マップからロケットを飛ばすことを目標にした。まず `uv` と Factorio LLM Use 0.1.1 を接続し、2.1.24 の新規試験ワールドで鉄板1枚の精錬と回収を確認した。これが接続・操作の最小単位になった。 [Factorio LLM Use](https://github.com/Tsyklop/factorio-llm-use)

敵から距離を取りつつ実績も狙えるマップを、という要望から初期シード `210539101` を選んだ。水で隔てられた開始側に原料が揃い、蒸気発電で最後まで進める計画だった。ウランを工程に入れる必要はなかった。資材・研究・発射を逆算し、配置と工区をブループリントにした。区間ごとに同じセーブを引き継ぐ方式で **5:49:24に衛星を打ち上げて勝利**。別の **3:59:38** はサイロ研究と発射用3素材が揃った地点の記録だった。終盤には紫・黄と発射素材が銅、鋼材、基板を取り合った。

Steamの個人実績ページで、11月22日17:31の「蒸気発電」、18:50の「雑談する暇はない」「弾丸の雨」「ずっと蒸気」「より多く製作」、21:02の「スプーンなんてない」を確認した（日本時間）。21:02の表示は、Luaで進めた旧シードのセーブを勝利直前から専用MODなしの2.1.24基本ゲームで再開し、ゲーム内5:49:24の勝利後に同名の通知が出た記録と一致する。 [Steam実績の確認記録](../../reference/development_evidence.json)

## 11月23日 · シード変更、通し比較、画面操作

利用者は離島に限定しない大規模なシード探索と、実地で供給の太い配置を試す方針を提案した。288シードと複数設定から1,279通りを比較し、海岸・石の頻度150%の **4263722700** を採用。銅まで23タイル、石炭まで18タイル、増設用地は128×128タイル。敵設定は有効で、調査した水で囲まれた開始側の陸地に巣・ワームは見つからなかった。油田までの約236タイルは配管で補う設計にした。 [実行するマップの設定](../../world/map-gen-settings.json)

初回45分では通電した電動掘削機7基、緑の消費15個だった。南東の銅、赤の組立機2基、電動石炭と鉄の順で立ち上げてから赤を4基へ増やした比較では **49基、緑218個**。給材・給電・搬出を揃えた列を小さく先行稼働させる理由になった。

利用者の要望でZasparの標準設定走を末尾まで通し再生し、工程標本と公開セーブの生産統計を照合した。**1:59:01** は登録上の実時間で、勝利画面はゲーム内 **1:58:32**。動画のタイマーは途中でリセットされたため、映像位置とセーブ時計を照合した。観測したのは作業・設備・流量で、クリック数や各操作の入力時間は測定対象外。旧1.1のRCU、マップ、敵、積み荷、時計の違いを残して比較した。 [標準設定走の勝利画面](https://www.youtube.com/watch?v=2PwyPjjoOJo&t=7153s)

標準設定走は0:20〜0:30に鉄板が約 **1,606枚/分**、初期自動化の同区間は約 **193枚/分**。1:42〜1:52には走者が青67、紫101、黄105個/分を出した。当時の試走では紫・黄がまだ生産されていなかった。配置と並んで、早期に設備を作れる部品の量、実際に動いた設備、配給と増設の時刻を追うようにした。 [比較の採録値](../../reference/development_evidence.json)

公開セーブでは主研究所56基のうち16基がベルトから受け、研究所間をインサータでつないでいた。サイロは生産力モジュール3を4個、周囲にビーコン20基。こちらはLuaで研究所に配給し、統合版のサイロには速度モジュール3を4個入れた。研究所とサイロは、並列化・連続給材を見習い、設備構成を試走の方式に合わせた。 [走者の主工場](https://www.youtube.com/watch?v=2PwyPjjoOJo&t=6428s) · [走者の発射直前](https://www.youtube.com/watch?v=2PwyPjjoOJo&t=7137s)

利用者が「研究の間に別の作業を進められないか」と尋ねたとき、137分の区間試験には新規施工指示が出なかった区間が4つあり、計55分44秒だった。これは意図的な測定区間も含み、その間に生産や研究は進んでいた。45分、96分などの固定着工時刻を観測の目安に移し、技術・部材・給電が揃えば油田、鋼材、蒸気の次の工区へ進める構成にした。鋼材の区間実験ではロボット12→24機で同じ584点の施工が12:02→6:19になった。

利用者からゲーム画面を見たいという依頼があった。Windowsの単発キー入力から、移動・採掘に必要な長押し入力へ切り替えると、画面上で鉄板1枚の回収を確認できた。別の表示用MODでも同じ工程を確認した。ロケットまでの通しには、実際のゲーム画面を出しながらLuaが操作を続ける方式を採用した。

## 11月24日 · 大規模生産を通しで試す

利用者の指摘は、後工程を止めるほど供給が細いラインを作らず、RTAを基準に生産・供給・電力を多めに確保することだった。増産を取り入れた通し試走は **7:27:37の段階試走から6:56:53**。新規マップから同じワールドを継いで途中修正した。序盤の鉄板75枚/分に対し歯車が余り、発電用の水は未接続の管へ行き、墜落船が電柱と回収口を塞いだ。終盤は黄用の制御基板とサイロ用電動エンジンが欠品した。工場が大きくなっても、増産が動き出す時刻と供給の順が残る課題だった。

待機短縮版は、最初の石炭6・鉄6・銅3掘削機、給電、蒸気部材を先取り。炉を鋼鉄の炉に更新し、余剰の固形燃料を蒸気へ回す。精油・分解も負荷に合わせて増やし、サイロ・衛星・降着パッドの準備を研究中に進めた。これで **2:13:44**。青の初生産は0:54で、サイロ研究の開始は1:56だった。1:45〜1:55には紫が17個/分まで細った。石レンガ・電気炉と石油ガス・プラスチックの不足を次の改善対象とした。 [配給修正前後のイベント](../../reference/development_evidence.json)

## 11月24日 · 2時間切りの組み合わせと再試走

| 青・鋼材・紫の取り合い | 青が細い間はエンジンとパイプを優先。レールの保管上限4,800→1,800本、鋼材炉の更新を前倒し。原石はレンガとレールの在庫で振り分け、石の掘削機20基に製造済みの速度モジュール1を各3個装着。統合版の石は毎分615→943個、紫は1:35〜1:40の47個/分から1:40〜1:45の100個/分へ回復。 |

| サイロ周辺の施工と速度 | 研究を終えた組立機3基を転用。解禁後に組立機を新設したときの墜落船・電柱の干渉を解消。速度モジュール3をサイロに4個入れ、設置から発射までを5:35→約2:15に短縮。 |

途中で修正を段階適用した試走で **1:50:27に発射**。全変更を最初から積んだ初回は **2:02:08**。電柱がつながらない候補地で施工が止まり、速度モジュール2・3が間に合わず、紫用のモジュールの給材も不足した。接続できない施工候補を飛ばし、紫用生産力モジュール1とサイロ用速度モジュール2・3を優先する修正を加えた。

新規開始から修正済みの同一コードを使った統合版は **1:49:38に発射、1:49:47に着荷**。65分で同じセーブをローカルサーバーへ継ぐ条件で2回測り、173件のイベント時刻が一致した。青の初生産は1:00と2:13:44の版より6分遅かったが、紫1:16、黄1:20、サイロ研究開始1:31:50まで前倒しでき、終点は24分06秒速かった。局所の開始時刻と全体の短縮を一緒に追う根拠になった。 [統合版のイベントとセーブ読み直し](../../reference/confirmed_runs.json)

## 11月24日 · 画面付き実演、配布用の再検証、先行例

同シードの画面付き先行試走は **1:52:59に発射**し、利用者も勝利画面を確認した。画面のプレイ時間 **1:53:21** には初期演出が入る。先行の配布準備ではプレイヤー作成前のセーブを使い、画面なしで発射と着荷、画面ありで蒸気発電後のカメラ切り替えまでを検証した。テストモードの完了判定は発射と着荷、画面付きの判定は発射と勝利イベントに合わせた。

公開用に開始セーブを手元のFactorio 2.1.25で生成する方式に変更した。画面なしで **1:50:18** に発射し、**1:50:27** に宇宙サイエンス1,000個が着荷した。先行の再検証と照合し、記録した172件のイベントが一致した。 [配布版の検証ログ](../../reference/package_verification.json)

公開前例として、Gotyokeの0.18.17のTAS **1:21:20** は実行用MODとソースが公開されている。Zasparの57:21には通し動画と制作説明がある。このプロジェクトの公開用説明では **Factorio 2.1.25、固定シード、Lua MOD自動運転、実測時計**を併記する。 [Gotyokeのソース](https://github.com/gotyoke/Factorio-AnyPct-TAS) · [再現用MOD](https://mods.factorio.com/mod/AnyPctTAS)
